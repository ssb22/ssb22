# Undergraduate Project Dissertation

My final-year undergraduate project in Computer Science was “A Representation and Conversion System for Musical Notation”.

An abridged version of this appeared in the Journal of Computing in Musicology (volume 12). Unfortunately I had to rush my proof-reading of the editorial work, so some passages may be unclear and/or erroneous. Please check the original (below) in case of any doubt.

* [Dissertation in HTML](https://ssb22.user.srcf.net/project/dissertation.html) (221 K + images) - not as complete as the PostScript, but the text is there
* [Dissertation in Markdown](dissertation.md) (similarly not quite complete but the text is there)
# Errata to the Dissertation
* Page 17: In footnote 14, for “row” read “column” (the diagram is correct).
* Appendix B: The entry for “prefixSmall” on page 64 should refer to 1/256 (not 256).
