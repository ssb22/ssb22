This copy of selected files in the top-level directory is here to work around an inconsistency in README linking between GitHub and GitLab.  As of December 2025, GitHub prepends the repository URL to any README.md link from the profile screen, but GitLab does not.  Furthermore, GitHub's README browser does not follow directory symlinks.  Therefore it is necessary either to maintain completely separate versions of the repository for these platforms, or to ensure URLs mentioned in the top-level README.md will work with or without a duplicate 'ssb22/ssb22/blob/main/' prefix.
