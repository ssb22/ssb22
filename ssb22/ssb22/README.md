These copies (with modified relative URLs) of selected files in the top-level directory are here to work around an inconsistency in README linking between GitHub and GitLab.  As of December 2025, GitHub prepends the repository URL to any absolute or relative README.md link from the profile screen, but GitLab does not.  Furthermore, GitHub's README browser does not follow directory symlinks.  Therefore it is necessary either to maintain completely separate versions of the repository for these platforms, or to prefix the links mentioned in the top-level README.md (for GitLab) and use duplicates to ensure the resulting URLs will work with or without an extra 'ssb22/ssb22/blob/main/' prefix (and also 'ssb22/ssb22/ssb22/blob/main' in case GitLab profile is accessed with a trailing slash, as it's better to stick with relative links for browsing a local clone of the repository).  For the record I still prefer my traditional home page where I can control the server and make sure it does something sensible, including proper rel=canonical and better accessibility, but these extra copies are unfortunately needed if some people are now trying to use 'AI' search and retrieval tools which seem more likely to index the major Git servers than a homepage.
